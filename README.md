# slu-pestcontrol

<!-- badges: start -->

<!-- badges: end -->

The goal of slu-pestcontrol is to perform data handling, statistical
analyses, academic article writing and scientific communication for the
research project “*Preparing Swedish agriculture for decreasing access
to chemical insecticides - vulnerability analysis and possible
alternatives*”. This project is hosted by the Swedish University of
Agricultural Sciences (Uppsala) and funded by the Swedish farmers’
foundation for agricultural research (*Stiftelsen Lantbruksforskning*,
\#O-25-20-074). Project leader is Ola Andreas Lundin (ORCID
0000-0002-5948-0761).
